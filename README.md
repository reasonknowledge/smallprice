# Smallprice
Pour lancer le projet, utilisez la commande suivante :
npm install pour installer les dépendances du projet
ensuite telecharger Expo Go sur votre telephone
puis lancez le projet avec la commande :
npx expo start et scannez le QR code avec l'application Expo Go pour voir le projet sur votre téléphone.

Vous devez egalement lancer le serveur backend ecrit en express en utilisant la commande :
npm run dev ,
